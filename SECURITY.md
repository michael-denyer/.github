# Security

This policy covers every public repository under [michael-denyer](https://github.com/michael-denyer) that does not ship its own `SECURITY.md`.

Report a vulnerability privately through the affected repository's **Security** tab, under **Report a vulnerability**. The form opens at `https://github.com/michael-denyer/<repository>/security/advisories/new`. Do not open a public issue for a vulnerability, because the issue tracker is public from the moment you press submit.

Include the affected version or commit, the component involved, and the impact you observed. A minimal reproduction with dummy data helps the investigation.

Use the private advisory to discuss a fix and agree on a disclosure date before publishing details.

Only the latest release, or the default branch where a project has no releases, receives fixes. There are no maintained release branches to back-port to.
